# About QuantumPools

QuantumPools is a multi-chain concentrated-liquidity **manager and analytics** platform.

**Main site:** https://app.quantumpools.io  
Marketing / metrics: https://quantumpools.io

Venue coverage includes Uniswap, PancakeSwap, Aerodrome, Orca, Meteora, and Solana (including Base), plus ETH hedging workflows. Features vary by venue and network. Production application source stays private; this repo is public project information only.
